Capacidades de Engenharia

Arquitetado para Performance Extrema. Sem Atalhos.

O CLOUDTRON OneClick reúne em um único executável tudo o que engenheiros exigem para operar modelos de 120B de parâmetros na rotina de código.

Zero Setup Local

Servidor HTTP nativo Node.js com streaming SSE bidirecional e empacotamento Electron leve. Esqueça dependências quebradas de Python e drivers CUDA incompatíveis.

Stack: Electron 34 • Node.js • Win x64

Deep Thinking (CoT) Inspecionável

Caixa retrátil dedicada para auditar o raciocínio analítico do Nemotron antes da resposta final. Transparência lógica completa para refatorações críticas.

Inspecionabilidade: Tag <thinking> nativa

Multimodalidade com Visão

Suporte nativo a Ctrl+V para colar capturas de tela, mockups do Figma ou logs de terminal, além de drag-and-drop de arquivos para contextualização imediata.

Entrada: PNG, JPEG, WEBP & Snippets

Live Sandbox Preview

Iframe isolado para executar e visualizar artefatos HTML5, CSS e JS criados pelo modelo em tempo real, sem poluir o contexto da conversa nem vazar escopo.

Ambiente: Iframe seguro com hot-reload

Diagnóstico em 2 Passos

Botão no cabeçalho do app que testa a conexão local com o backend e valida a chave nvapi-... diretamente no endpoint oficial da NVIDIA NIM.

Telemetria: NVIDIA NIM Latency Test

Motor Heurístico Adaptativo

Modulação automática de hiperparâmetros (Código, Profundo, Criativo e Rápido) com base no prompt para equilibrar criatividade e rigidez determinística.

Modos: Código • CoT • Rápido • Livre
Inovação Exclusiva v1.3.0

Closed-Loop Intelligence: Auto-Correção Ativa via NVIDIA NeMo Judge

Esqueça LLMs que repetem os mesmos erros. O Cloudtron OneClick v1.3.0 implementa In-Context RLHF em tempo de execução: cada resposta é auditada sintaticamente por um LLM-as-a-Judge independente. Caso ocorram advertências ou inconformidades, a crítica técnica é injetada automaticamente no turno seguinte, forçando o modelo a recalibrar precisão, arquitetura e fechamento de sintaxe sem requerer prompts corretivos do usuário.

Auditoria LLM-as-a-Judge In-Context Calibration Zero Alucinação Repetida
Engine: NeMo Guardrails Core
Topologia de Engenharia

Como o CLOUDTRON OneClick Funciona

Uma arquitetura híbrida de alto desempenho que transfere o peso computacional de 120 bilhões de parâmetros para a nuvem da NVIDIA, mantendo a experiência local ultrarrápida.

01 • DESKTOP RUNTIME

Electron 34 + Node.js

Shell leve empacotado em executável NSIS para Windows x64. Consumo mínimo de RAM (<120MB) e interface acelerada por hardware nativo.

> 0 GB VRAM Local
> 0 Drivers CUDA exigidos
02 • BACKEND SSE PROXY

Pipeline HTTP Streaming

Servidor HTTP interno em `server.js` gerencia buffers de streaming Server-Sent Events (SSE), parseia Markdown progressivo e sanitiza payloads multimodais.

> Localhost:3000 IPC
> First Token: ~110ms
03 • CLOUD INFERENCE

NVIDIA NIM Cluster

Comunicação segura com a API oficial da NVIDIA NIM executando o modelo Nemotron 3.5 Super VL 120B com aceleração nos clusters H100/A100 Tensor Core.

> Endpoint: build.nvidia.com
> Autenticação: nvapi-***
